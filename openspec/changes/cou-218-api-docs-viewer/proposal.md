# Proposal: Add Scalar API Documentation Viewer

## Intent

Replace the dated Swagger UI with a modern, interactive API documentation viewer (Scalar) while maintaining backward compatibility. Current Swagger UI at `/docs` lacks dark mode, client code generation, and modern UX that Scalar provides out of the box.

## Scope

### In Scope
- Install `@scalar/nestjs-api-reference` package
- Mount Scalar at `/reference` alongside existing Swagger UI at `/docs`
- Wire Scalar to the same OpenAPI document generated by `@nestjs/swagger`

### Out of Scope
- Removing or disabling Swagger UI at `/docs`
- Changing how the OpenAPI spec is generated (decorators, DocumentBuilder config)
- Adding authentication to the docs endpoints

## Capabilities

### New Capabilities
- `api-docs-viewer`: Serve interactive API documentation via Scalar at `/reference`, consuming the existing OpenAPI document generated by `@nestjs/swagger`

### Modified Capabilities
None

## Approach

1. `npm install @scalar/nestjs-api-reference`
2. In `src/main.ts`, after `SwaggerModule.createDocument()`, register the Scalar middleware:
   ```ts
   import { apiReference } from '@scalar/nestjs-api-reference';
   app.use('/reference', apiReference({ spec: { content: swaggerDocument } }));
   ```
3. No route collision — Scalar uses Fastify middleware mounting; Swagger UI remains at `/docs`

## Affected Areas

| Area | Impact | Description |
|------|--------|-------------|
| `src/main.ts` | Modified | Import + 1 line to register Scalar middleware |
| `package.json` | Modified | New dependency: `@scalar/nestjs-api-reference` |

## Risks

| Risk | Likelihood | Mitigation |
|------|------------|------------|
| `@scalar/nestjs-api-reference` Fastify compatibility issue | Low | Scalar supports Fastify via `app.use()`; if blocked, fall back to `@scalar/express-api-reference` with Fastify's `@fastify/express` plugin |
| Package version conflicts with NestJS 11 peer deps | Low | Pin compatible version; Scalar's NestJS package is framework-agnostic at the middleware level |

## Rollback Plan

1. Remove the `import` and `app.use('/reference', ...)` line from `src/main.ts`
2. `npm uninstall @scalar/nestjs-api-reference`
3. Swagger UI at `/docs` remains untouched — zero impact

## Dependencies

- `@scalar/nestjs-api-reference` (latest stable)
- Existing `@nestjs/swagger` v11 (unchanged)

## Success Criteria

- [ ] `GET /reference` returns Scalar's interactive docs UI (HTTP 200)
- [ ] Scalar renders all endpoints from the existing OpenAPI spec
- [ ] Swagger UI at `/docs` continues working unchanged
- [ ] No test regressions in existing test suite
